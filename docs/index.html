How it works

Not a posting tool. Not a dashboard. The prediction layer that makes agents better marketers.

1

Five inputs

Who is posting (author + engagement baseline). What they're saying (content). When it goes live (planned post time). Where (X for now). Target (impressions + timeframe).

2

PostProphet predicts

Probability the content hits the target within the timeframe — plus reasoning explaining why and what would increase it. Factors in author baseline, recent top tweets, trending topics, and time of day.

3

Agent iterates

Low probability? The reasoning tells the agent what to change. Modify, re-predict, repeat until it clears the threshold. Then ship.

The eval

Live, real-time, ungameable. The same pattern Numinous uses for event forecasting — applied to social media.

LIVE DATA

Real tweets, real resolution

X API filtered stream captures tweets the moment they're posted. The engine predicts. Impressions resolve naturally over the timeframe. No sandbox, no historical replay.

BRIER SCORE

Probability calibration

Standard forecasting metric. How well does the engine's probability match reality? 100 tweets per batch, rolling window, same scoring as prediction markets.

REGRESSION TESTING

PRs scored against real outcomes

Change the prediction logic, rerun against the same tweet batch. Did accuracy improve? Merge. Did it regress? Revert. Same pattern as SparkDistill and Ninja.
